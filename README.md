# Mesh devices comparison list -- buying guide

The `main` branch is automatically deployed to [mesh.arli21.me](mesh.arli21.me) via GitHub Pages.

Feel free to contribute, the structure of the CSV and of `index.html` should be pretty self-explanatory, but feel free to drop me an e-mail/message on GitHub or any means of communication listed on [arli21.me](arli21.me) should you need some assistance.

The stack is basically Vanilla JS + Tabulator.

## AI Policy

Use of LLMs/generative AI when contributing to this repo is **strongly discouraged**. 

Any data addition should be appropriately and precisely sourced, and any large pull request which I deem vibe-coded will be declined (feel free to fork ;)).

Use of AI-assisted research to add new devices is OK as long as you don't brag about it, **and as long as you can give sources for your data addition**.

You do you, if your AI-made/AI-assisted contribution is good enough not to seem to be written by an AI, well it's your lucky day x)

Thank you for respecting this policy, cheers
