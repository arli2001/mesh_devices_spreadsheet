# Mesh devices comparison list -- buying guide

The `main` branch is automatically deployed to [mesh.arli21.me](mesh.arli21.me) via GitHub Pages.

Feel free to contribute, the structure of the CSV and of `index.html` should be pretty self-explanatory, but feel free to drop me an e-mail/message on GitHub or any means of communication listed on [arli21.me](arli21.me) should you need some assistance.

The stack is basically Vanilla JS + Tabulator.
